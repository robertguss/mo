# Planted changes, set 1

The session `phase6-planted-changes-1` (a Claude subagent, id `a22e5863010ada85e`) wrote this set, and it was frozen on 2026-11-14 before the door's proof ran. The session that built the door started it; it wrote none of the task queue's intent. It was given the task queue's `main.mo` and `job-queue.mo`, the language reference and agent guide, a frozen `mo` binary limited to `mo check` and plain `mo test`, and the door's rule in words. It was not given the door's source, `mo intent`, `mo review`, the test listing or strength output, or the door's design notes. Every kind below is this session's own judgment. Each of `p01` to `p20` holds only the files that change replaces, in full. All of them pass `mo check` and plain `mo test` on both files. `manifest.json` records the SHA-256 of the original files and of every file written.

The set has two kinds, ten of each, shuffled across the ids. A `fix` leaves the content of every approved promise and example row unchanged, and the service still calls every function an approved item is about. An `intent` change edits or removes an approved item. It does that by rewording or changing a promise, deleting or changing an example row, changing a constant, helper, anchor-reached function or signature an item reads, or leaving a function with approved items uncalled by the service.
