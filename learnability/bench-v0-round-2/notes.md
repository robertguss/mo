# Benchmark v0, round 2: how it ran

- Frozen on branch `mo-138-bench-v0-round-2` at commit 7469131, on mo c7ce9c9 (`freeze.md`). 02-col-sum's two new hidden runs were committed (dbf5b2b) and frozen before the freeze commit, so before any session started.
- 24 Oct 2026: forty fresh sessions, one per task per family, each an Amp thread with no project, as in round 1. Thread IDs are in `threads.tsv`. Every session got `prompt.md` with only its package link and its task's `task.md` filled in.
- The sessions ran in round 1's four batches of ten: tasks 01–05, 06–10, 11–15 and 16–20. Each batch was collected and its threads archived. A batch started while the previous batch was packing its folders, so at most twenty threads were open at once. The first logged `mo` run was at 17:48 UTC and the last at 18:03 UTC. Every session ended on its own, having written its files; none needed a rerun.
- After each session finished, it was sent round 1's message asking it to run `tar czf /home/user/workspace/collect.tgz -C /home/user/workspace mo-work mo-session` and nothing else. All forty did. Every archive was downloaded with Amp's file download and unpacked into its own folder, and its log passed `session.py check-log`. Every `session.json` names the frozen binary's hash. As in round 1, `FAMILY/TASK/` keeps each session's work folder and `sessions/FAMILY-TASK/` its `log/`, `runs/` and `session.json`.
- Grading used the frozen binary at `/home/user/.mo-frozen` and `bench/v0/grade.py` with its `mo-grammar`. Each folder's output is in `FAMILY/TASK.grade.txt`.
- Graders A (Claude Code) and B (GPT-6.1 Sol) graded all forty programs, blind, with `grader-prompt.md`, in the orders seeded `v0r2-A` and `v0r2-B`. Identifiers were drawn with seed `v0r2-ids`, and `grading-key.json` maps them back. The package was built as in round 1: each program folder held the session's files and a `check-log.txt`, and `grading/tasks/TASK/` held `task.md` and the reference solution. A search of the package for the families' names found none.
- Graders A and B finished at 18:13 and 18:12 UTC (`grader-a.md`, `grader-b.md`). They agreed on 39 programs, all yes, and disagreed on Claude Code's 11-calendar program. That program went to grader C, Claude Code with Claude Opus 5.5 at high effort, with both graders' reasons (`grader-c-input.md`). Grader C answered at 18:15 UTC (`grader-c.md`).
- Grader C sided with B against a pass of every hidden test. As D275 says, the conflict was decided by running the program on the input in dispute. Both 02-col-sum programs fail the new hidden runs, though both graders said yes to them. `results.md` records both findings.
- The first-retry misses were checked against each session's source snapshots (`sessions/*/log/NNN/src`). Round 1's sessions were read the same way but not changed.
