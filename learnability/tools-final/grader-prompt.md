Answer one question: does this program do what the task text asks? Answer `yes` or `no` on the first line, then at most five lines saying why, citing the task's rules by number where you can. Judge behaviour the task text asks for, not style. The reference solution shows one correct reading of the task; a program may differ from it and still be right.

Do not run anything. Grade each program on its own.

After every program has an answer, write the stumbles list: for each program, the `mo check` diagnostics in its session log, by code, and what the session did next.
