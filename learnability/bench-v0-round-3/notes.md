# Benchmark v0, round 3: how it ran

- Frozen on branch `mo-148-bench-v0-round-3` at commit 0681152, on mo 31c0f8c (`freeze.md`). 11-calendar's new hidden test was committed (c2775b4) and frozen before the freeze commit, so before any session started.
- 24 Oct 2026: forty fresh sessions, one per task per family, each an Amp thread with no project, as in rounds 1 and 2. Thread IDs are in `threads.tsv`. Every session got `prompt.md` with only its package link and its task's `task.md` filled in. Packages were delivered with Amp's temporary file links.
- The sessions ran in round 1's four batches of ten: tasks 01–05, 06–10, 11–15 and 16–20. Each batch was collected and its threads archived. As in round 2, a batch started while the previous batch was packing its folders, so at most twenty threads were open at once. The first recorded `mo` run was at 19:11 UTC and the last at 19:30 UTC. Every session ended on its own, having written its files; none needed a rerun.
- After each session finished, it was sent round 1's message asking it to run `tar czf /home/user/workspace/collect.tgz -C /home/user/workspace mo-work mo-session` and nothing else. All forty did. Every archive was downloaded with Amp's file download and unpacked into its own folder, and its log passed `session.py check-log`. Every `session.json` names the frozen binary's hash. As before, `FAMILY/TASK/` keeps each session's work folder and `sessions/FAMILY-TASK/` its `log/`, `runs/` and `session.json`.
- One session, Claude Code's 15-parking, also sent this coordinator a short report of its fix when it finished. It needed no reply and got none.
- Grading used the frozen binary at `/home/user/.mo-frozen` and `bench/v0/grade.py` with its `mo-grammar`. Each folder's output is in `FAMILY/TASK.grade.txt`.
- Graders A (Claude Code) and B (GPT-6.1 Sol) graded all forty programs, blind, with `grader-prompt.md`, in the orders seeded `v0r3-A` and `v0r3-B`. Identifiers were drawn with seed `v0r3-ids`, and `grading-key.json` maps them back. The package was built as in round 2, and a search of it for the families' names found none.
- Graders A and B finished at 19:43 and 19:47 UTC (`grader-a.md`, `grader-b.md`). They agreed on 39 programs, all yes, and disagreed on Claude Code's 02-col-sum. That program went to grader C, Claude Code with Claude Opus 5.5 at high effort, with both graders' reasons (`grader-c-input.md`). Grader C answered at 19:49 UTC (`grader-c.md`), siding with B. That agrees with the hidden tests, so no conflict was left to decide.
- The first-retry miss and the edited-before-re-run count were checked against each session's source snapshots (`sessions/*/log/NNN/src`), by diffing each run's snapshot with the next. Rounds 1 and 2's records were not changed.
