# Contributing

Thanks for your interest in Mo.

Mo is currently at **v0.3.0** (pre-release) and is not yet accepting external pull requests while the language and runtime stabilize through daily use. Watch or star the repository—or open an issue to report a bug or share feedback—to follow along.

If you are building locally to explore the toolchain:

```sh
cargo build --release --bin mo
bash ci/check.sh rust
```

This file will expand with full contribution guidelines once Mo opens for external pull requests.
