### 13.4 The `mo` command
Each command is given the file of the program's main module; `mo check` and `mo test` also accept a library module. `mo check FILE` reports the program's errors, `mo run FILE [ARGS...]` runs it with the arguments after the file's name, and `mo test FILE` checks its examples, promises and tests. `mo format` and `mo fix` rewrite the files they are given. `mo guide` needs no file. It prints a short guide for agents writing Mo, matched to the installed version: how to work with the `mo` command, a small complete program with its tests, and when a task is done. `mo guide --reference` prints this reference. `mo` exits with status 0 when everything passed, 1 when the program has errors or an example, promise or test fails, and 2 for a mistake in the command itself. Once the program runs, `mo run` exits with the program's own status (section 11.2), or 70 after a bug (section 13.2).
`mo test` runs every example, promise and test unless it's told which. Each has a full name: its function's name, or a test's module's, then its kind and a number counted from 1 in source order, such as `Wc.count.example.3` for the third example of `Wc.count`, `Account.transfer.promise.1`, or `Wc.test.2` for the second test in `Wc`. `--only NAME` runs the one with that full name, and can be given more than once; `--in MODULE` runs one module's, still checking the whole program; and `--list` prints the full names without running anything. A selection that matches nothing is a mistake in the command.
`mo run` and `mo test` limit what a program uses: `--max-stack` sets the bytes of stack, by default 8 MiB; `--max-depth` the calls in progress at once, by default 10,000; and `--max-heap` the bytes of memory, by default 1 GiB. Going past one is a bug whose report names the limit (section 13.2). A call in tail position takes its caller's place on the stack and doesn't count toward the depth (section 5.3). A program can't set its own limits.
`mo check --json` and `mo test --json` write one JSON object per line to standard output: first the format's version, then one for each error and for each example, promise and test run, and last the totals and the exit status. Within a major version of the format, every field keeps its name, type and meaning, and an error's code keeps its meaning; new fields and new kinds of object may be added, so a reader skips what it doesn't know. A message's wording may change.
## 14. The core library
Each function is listed under the type of its first parameter, written as it is called with a dot: under **Text**, `split(separator: Text) : List(Text)` is called as `text.split(",")`. A function written `Type.name(...)` is called through the type's module. `pred` is a function returning a `Bool`. Calling a function outside what it accepts, such as `take(-1)`, is a bug (section 13.2). Every type with the `Text` ability also has `to_text : Text`, its text form, and every type with `Order` has `compare(other: T) : Ordering` (section 9.2).
**Int**: `abs`, `min(b: Int)`, `max(b: Int)`, `pow(n: Int)` (`n` at least 0), `floor_div(b: Int)`, `floor_mod(b: Int)`, and `wrapping_add`, `wrapping_sub`, `wrapping_mul`, `saturating_add`, `saturating_sub` and `saturating_mul` (each taking `b: Int`), all `: Int`. `checked_add`, `checked_sub` and `checked_mul` `(b: Int) : Option(Int)`. `to_decimal : Decimal`, `to_float : Float` (rounded to the nearest float), `to_big : BigInt`, `to_byte : Option(Byte)`, `to_char : Option(Char)`, `to_text : Text`. `seconds`, `milliseconds`, `minutes`, `hours` and `days : Duration`.
**BigInt**: the arithmetic operators, `abs`, `min(b: BigInt)`, `max(b: BigInt)`, `pow(n: Int)`, `floor_div(b: BigInt)` and `floor_mod(b: BigInt)`, all `: BigInt`; `to_int : Option(Int)`, `to_text : Text`. **Byte**: `to_int : Int`, `to_text : Text`.
**Decimal**: `abs`, `min(b: Decimal)`, `max(b: Decimal)`, `round(places: Int)` (ties away from zero), `floor` and `ceil`, all `: Decimal`. `to_int : Option(Int)` (`None` unless whole and in range), `to_float : Float` (rounded to the nearest float), `to_fixed(places: Int) : Text` (rounded as `round` does), `to_text : Text`. `places` is from 0 to 18.
**Float**: `abs`, `floor`, `ceil`, `round` (ties away from zero) and `sqrt`, all `: Float`; `nan?` and `infinite? : Bool`; `to_decimal : Option(Decimal)`: the number the float's text form writes, rounded to 18 places with ties to even, so `0.1.to_decimal` is `Some(0.1)`, and `None` for not-a-number, the infinities and anything beyond `Decimal`'s range; `to_text : Text`.
**Text**: `byte_count : Int`, `char_count : Int`, `empty? : Bool`, `chars : List(Char)`, `bytes : Bytes`. `lines : List(Text)`: split where `\n` or `\r\n` ends a line, without the line endings; `""` has none, a final line break doesn't start another line, and a `\r` alone stays in its line. `words : List(Text)`: split at ASCII white space, which alone gives none. ASCII white space is space, tab, line feed, vertical tab, form feed and carriage return. `split(separator: Text) : List(Text)`: the separator isn't empty, and empty pieces are kept, so `"".split(",")` is `[""]`. `trim`, `trim_start` and `trim_end : Text` (ASCII white space). `starts_with?(prefix: Text)`, `ends_with?(suffix: Text)` and `contains?(part: Text) : Bool`. `drop_prefix(prefix: Text)` and `drop_suffix(suffix: Text) : Option(Text)`: `None` when the text doesn't have it. `replace(old: Text, new: Text)` (`old` isn't empty), `repeat(n: Int)` (`n` is at least 0), `pad_left(width: Int)` and `pad_right(width: Int)`, all `: Text`; padding adds spaces, counting characters, and leaves text that is already as wide, or wider, unchanged, even for a width below 0. `ascii_lowercase` and `ascii_uppercase : Text`. `to_int : Option(Int)`: an optional `-` and ASCII digits, in the `Int` range, and nothing else. `to_decimal : Option(Decimal)`: an optional `-`, one or more ASCII digits, then optionally `.` and 1 to 18 digits, in the `Decimal` range, and nothing else, so `"1."` and `".5"` give `None`. `to_float : Option(Float)`: an optional `-`, one or more ASCII digits, optionally `.` and one or more digits, and optionally `e` or `E`, an optional sign and one or more digits; or exactly `nan`, `inf` or `-inf`, the text forms of section 9.2. It gives the nearest float, and `None` for anything else or for a number too large to be a finite `Float`. `Text.from_chars(chars: List(Char)) : Text`.
**Char**: `code : Int`, `ascii_digit?`, `ascii_letter?` and `ascii_white_space? : Bool`, `ascii_lowercase` and `ascii_uppercase : Char`, `to_text : Text`.
**Bytes**: `size : Int`, `get(i: Int) : Option(Byte)`, `decode_utf8 : Option(Text)`.
**List(T)**: `size : Int`, `empty? : Bool`. `get(i: Int)`, `first` and `last : Option(T)`; `get` gives `None` for a position below 0 or past the end. `append(x: T)`, `prepend(x: T)`, `concat(other: List(T))`, `reverse`, `take(n: Int)` and `drop(n: Int)`, all `: List(T)`; `n` is at least 0, and past the end they take or drop everything. `set(i: Int, x: T)` and `remove_at(i: Int) : Option(List(T))`: `None` for a position that isn't there. `map(f: fn(T) : U) : List(U)`, `filter(pred) : List(T)`, `filter_map(f: fn(T) : Option(U)) : List(U)` (the values in the `Some`s), `flat_map(f: fn(T) : List(U)) : List(U)`, `reduce(start: A, f: fn(A, T) : A) : A` (from the left), `find(pred) : Option(T)`, `any?(pred)` and `all?(pred) : Bool`, `count(pred) : Int`, `enumerate : List((Int, T))` (from 0), `zip(other: List(U)) : List((T, U))` (as long as the shorter list). `sort_by(key: fn(T) : K)` and `sort_by_desc(key: fn(T) : K) : List(T)` where `K: Order`. `contains?(x: T) : Bool` where `T: Equal`. `sort : List(T)`, and `min` and `max : Option(T)` (the first of equal elements), where `T: Order`. `unique : List(T)`, `to_set : Set(T)` and `group_by(key: fn(T) : K) : Map(K, List(T))` (keys in the order they first appear), where `T` or `K` has `Hash`. `sum : T` where `T: Number` (`0` for an empty list). On a `List(Text)`, `join(separator: Text) : Text`; on a `List((K, V))`, `to_map : Map(K, V)`, in which a key given more than once gets its last value and keeps its first place, as with `set`.
**Map(K, V)**: `size : Int`, `empty? : Bool`, `get(key: K) : Option(V)`, `has?(key: K) : Bool`, `set(key: K, value: V)`, `remove(key: K)` and `update(key: K, default: V, f: fn(V) : V)`, all `: Map(K, V)`; `update` sets the key to `f` of its value, or of `default` when it has none. `keys : List(K)`, `values : List(V)` and `entries : List((K, V))`, in insertion order.
**Set(T)**: `size : Int`, `empty? : Bool`, `has?(x: T) : Bool`; `add(x: T)`, `remove(x: T)`, `union(other: Set(T))`, `intersection(other: Set(T))` and `difference(other: Set(T))`, all `: Set(T)`; `to_list : List(T)`. `Set.empty` is a constant: the empty set.
**Range**: `for` loops over it; `to_list : List(Int)`, `contains?(n: Int) : Bool`.
**Option(T)**: `x or default` (an operator) gives a `T`; `or_fail(e: E) : Result(T, E)`; `map(f: fn(T) : U) : Option(U)`.
**Result(T, E)**: `map(f: fn(T) : U) : Result(U, E)`, `map_error(f: fn(E) : F) : Result(T, F)`.
**Time**: `checked_add(d: Duration) : Option(Time)`, `to_text : Text`, and the operators of section 3.9. `to_text` writes RFC 3339 in UTC, with `Z`, and a fraction of a second only when there is one, as short as it can be: `2026-10-12T02:15:00Z`, `2026-10-12T02:15:00.5Z`. `Time.parse(text: Text) : Option(Time)` reads RFC 3339 text, such as `2026-10-12T04:15:00.5+02:00`: `T` or `t` between the date and the time, at most 6 digits of a fraction of a second, then `Z`, `z` or an offset, which it converts to UTC. Anything else, including a 7th fraction digit or a leap second (second 60), gives `None`. **Duration**: `in_milliseconds : Int` (rounded toward zero), `in_seconds : Decimal` (exact), `to_text : Text`.
**Args**: `list : List(Text)`, the arguments after the program's name. **Env**: `get(name: Text) : Option(Text)`.
**Console**: `print(text: Text)` and `error(text: Text)` write a line to standard output or standard error; print other values with interpolation, as in `console.print("#{count}")`. `read_line : Option(Text)` reads a line from standard input, without its line ending, `\n` or `\r\n`, and gives `None` at the input's end. Each sequence of bytes in it that isn't valid UTF-8 becomes one U+FFFD, the replacement character. A fake also has `printed` and `printed_errors : List(Text)`, with one entry for each line written. Using them outside tests, examples and promises is an error (section 12.4). `Console.fake() : Console`, `Console.fake_input(lines: List(Text)) : Console`.
