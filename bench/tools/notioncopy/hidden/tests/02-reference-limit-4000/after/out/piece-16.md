**List(T)**: `size : Int`, `empty? : Bool`. `get(i: Int)`, `first` and `last : Option(T)`; `get` gives `None` for a position below 0 or past the end. `append(x: T)`, `prepend(x: T)`, `concat(other: List(T))`, `reverse`, `take(n: Int)` and `drop(n: Int)`, all `: List(T)`; `n` is at least 0, and past the end they take or drop everything. `set(i: Int, x: T)` and `remove_at(i: Int) : Option(List(T))`: `None` for a position that isn't there. `map(f: fn(T) : U) : List(U)`, `filter(pred) : List(T)`, `filter_map(f: fn(T) : Option(U)) : List(U)` (the values in the `Some`s), `flat_map(f: fn(T) : List(U)) : List(U)`, `reduce(start: A, f: fn(A, T) : A) : A` (from the left), `find(pred) : Option(T)`, `any?(pred)` and `all?(pred) : Bool`, `count(pred) : Int`, `enumerate : List((Int, T))` (from 0), `zip(other: List(U)) : List((T, U))` (as long as the shorter list). `sort_by(key: fn(T) : K)` and `sort_by_desc(key: fn(T) : K) : List(T)` where `K: Order`. `contains?(x: T) : Bool` where `T: Equal`. `sort : List(T)`, and `min` and `max : Option(T)` (the first of equal elements), where `T: Order`. `unique : List(T)`, `to_set : Set(T)` and `group_by(key: fn(T) : K) : Map(K, List(T))` (keys in the order they first appear), where `T` or `K` has `Hash`. `sum : T` where `T: Number` (`0` for an empty list). On a `List(Text)`, `join(separator: Text) : Text`; on a `List((K, V))`, `to_map : Map(K, V)`, in which a key given more than once gets its last value and keeps its first place, as with `set`.
**Map(K, V)**: `size : Int`, `empty? : Bool`, `get(key: K) : Option(V)`, `has?(key: K) : Bool`, `set(key: K, value: V)`, `remove(key: K)` and `update(key: K, default: V, f: fn(V) : V)`, all `: Map(K, V)`; `update` sets the key to `f` of its value, or of `default` when it has none. `keys : List(K)`, `values : List(V)` and `entries : List((K, V))`, in insertion order.
**Set(T)**: `size : Int`, `empty? : Bool`, `has?(x: T) : Bool`; `add(x: T)`, `remove(x: T)`, `union(other: Set(T))`, `intersection(other: Set(T))` and `difference(other: Set(T))`, all `: Set(T)`; `to_list : List(T)`. `Set.empty` is a constant: the empty set.
**Range**: `for` loops over it; `to_list : List(Int)`, `contains?(n: Int) : Bool`.
**Option(T)**: `x or default` (an operator) gives a `T`; `or_fail(e: E) : Result(T, E)`; `map(f: fn(T) : U) : Option(U)`.
**Result(T, E)**: `map(f: fn(T) : U) : Result(U, E)`, `map_error(f: fn(E) : F) : Result(T, F)`.
**Time**: `checked_add(d: Duration) : Option(Time)`, `to_text : Text`, and the operators of section 3.9. `to_text` writes RFC 3339 in UTC, with `Z`, and a fraction of a second only when there is one, as short as it can be: `2026-10-12T02:15:00Z`, `2026-10-12T02:15:00.5Z`. `Time.parse(text: Text) : Option(Time)` reads RFC 3339 text, such as `2026-10-12T04:15:00.5+02:00`: `T` or `t` between the date and the time, at most 6 digits of a fraction of a second, then `Z`, `z` or an offset, which it converts to UTC. Anything else, including a 7th fraction digit or a leap second (second 60), gives `None`. **Duration**: `in_milliseconds : Int` (rounded toward zero), `in_seconds : Decimal` (exact), `to_text : Text`.
**Args**: `list : List(Text)`, the arguments after the program's name. **Env**: `get(name: Text) : Option(Text)`.
**Console**: `print(text: Text)` and `error(text: Text)` write a line to standard output or standard error; print other values with interpolation, as in `console.print("#{count}")`. `read_line : Option(Text)` reads a line from standard input, without its line ending, `\n` or `\r\n`, and gives `None` at the input's end. Each sequence of bytes in it that isn't valid UTF-8 becomes one U+FFFD, the replacement character. A fake also has `printed` and `printed_errors : List(Text)`, with one entry for each line written. Using them outside tests, examples and promises is an error (section 12.4). `Console.fake() : Console`, `Console.fake_input(lines: List(Text)) : Console`.
